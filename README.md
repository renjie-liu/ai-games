# ai-games
AI-vibe coded games

## Games

- [`ironyard/`](ironyard/) — **Ironyard 铁场**. An agent builds a car out of bricks within a budget, then writes the controller that drives it; matches run offline and come out the same every time. 1v1 / 2v2 / 3v3, seven maps, pickups, and an MCP server so a player's own agent can design and test. Node 20+. Open `ironyard/dist/index.html` to watch a match, or read the [README](ironyard/README.md).
