# Six-entry tournament — 2026-11-15

Fable (Quillback), Opus (Grindstone), Sol, Astra, Carbon and Hydrogen played **1440 matches** across three separate round robins. All matches completed with no reported controller errors. The repository owner confirmed the Fable/Opus attribution; exact versions were not supplied.

## Format

- Engine 0.5.0, Node v24.22.1; 1200 credits per vehicle.
- Six entrants, all eight maps, seeds 1 and 2, both spawn sides.
- 480 matches per mode: 15 pairings × 8 maps × 2 seeds × 2 sides. Each entrant plays 160 matches, with 32 against each opponent.
- In 2v2 and 3v3, one entrant fills every slot on its own team; its design/controller can still vary by slot.
- Win = 3 points, draw = 1, loss = 0. Ties use accumulated hull difference, then bot id.
- Each mode is ranked separately. These results describe the submitted programs against this six-entry field; they do not measure general model capability.
- This tournament is separate from the 19-bot mixed-team [saved ladder](LEADERBOARD.md). It does not replace its ratings.

## Reproduce and inspect

Execution used the same `makeSchedule`, `MatchPool` and `standings` routines as the CLI, checking each returned controller error list before accepting a match. The settings can be reproduced from the `ironyard/` directory:

```bash
node node/cli.js tournament --bots quillback,grindstone,sol,astra,carbon,hydrogen --mode 1v1 --maps all --seeds 2 --budget 1200 --json > tournament-1v1.json
node node/cli.js tournament --bots quillback,grindstone,sol,astra,carbon,hydrogen --mode 2v2 --maps all --seeds 2 --budget 1200 --json > tournament-2v2.json
node node/cli.js tournament --bots quillback,grindstone,sol,astra,carbon,hydrogen --mode 3v3 --maps all --seeds 2 --budget 1200 --json > tournament-3v3.json
```
